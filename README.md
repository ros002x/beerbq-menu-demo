# BeerBQ — Menu demo

Demo del nuovo menu digitale per BeerBQ, Nova Siri.

Il progetto è una pagina statica responsive realizzata con HTML, CSS e JavaScript. Le fotografie dei prodotti provengono dalla libreria media ufficiale BeerBQ.

## Struttura

```text
BeerBQ/
├─ index.html
├─ README.md
├─ .nojekyll
└─ assets/
   ├─ css/
   │  └─ style.css
   ├─ js/
   │  └─ script.js
   └─ images/
      ├─ beerbq-logo.png
      └─ foto prodotti
```

## Avvio locale

Aprire `index.html` nel browser.
